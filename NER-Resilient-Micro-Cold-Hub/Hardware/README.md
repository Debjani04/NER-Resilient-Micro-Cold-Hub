# Hardware / Prototype

The software model is intended to support a small physical validation prototype.

Planned/used system elements include:

- Insulated cold-storage chamber
- DC refrigeration system
- A13 PCM thermal buffer
- ESP32 controller
- Chamber/product temperature sensors
- Ambient temperature and RH sensing
- Compressor current sensing
- PV voltage/current sensing
- Battery voltage/current sensing
- Door-state sensing
- DC fan and protection circuitry

The hardware layer should be experimentally calibrated against the Simulink model before making commercial-scale performance claims.
